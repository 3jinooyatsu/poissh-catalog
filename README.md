# poissh-catalog

iOSアプリ **Poissh（ポイッシュ）** が読むカタログ。

- `catalog.json` — 登録できるアプリ（プリセット）と、チェーンごとの受け入れポイント・
  提示の制約・還元率（StoreTemplate）

## なぜ配信するか

URLスキーム・共通ポイントの対応・還元率は**他社の都合で変わる**。アプリに同梱するだけだと
審査を通さないと直せないので、ここから配信して当日中に反映できるようにしている。

## アプリ側の扱い

- アプリに同梱された `catalog.json` が常に下限。ここが落ちても圏外でもアプリは動く
- 起動時に取得（6時間に1回まで・待たない）し、検証に通ればキャッシュ
- **反映は次回起動から**（動作中に手順が入れ替わる方が危ない）
- 検証: デコード可 / presets・storeTemplates が空でない / 2MB以下 / `version` が上

`version` を上げ忘れた配信は無視される。
